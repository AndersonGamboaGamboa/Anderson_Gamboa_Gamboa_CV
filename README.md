# Anderson Gamboa Gamboa
## Portafolio de evidencias · Desarrollo de software

Selección de proyectos de gestión agropecuaria con aplicaciones móviles, servicios de backend y reglas de negocio verificables.

**Tecnologías presentes:** C#, ASP.NET Core, .NET MAUI, TypeScript, React Native, Expo, MySQL y PostgreSQL.

### Proyectos seleccionados

| Proyecto | Problema que aborda | Evidencia técnica | Caso |
|---|---|---|---|
| Ganado Manager | Registro de animales, movimientos, inventarios y costos de una finca | Regresión e integración MySQL aprobadas en GitHub Actions | [Ver caso](proyectos/ganado-manager.md) |
| Porcino Manager | Control de engorde por corrales, alimentación, medicamentos y ventas | 47 pruebas móviles aprobadas en la revisión | [Ver caso](proyectos/porcino-manager.md) |
| Cosecha Manager | Registro de recolección de café, pagos y saldos por trabajador | 13 pruebas de dominio y estados de cuenta aprobadas en la revisión | [Ver caso](proyectos/cosecha-manager.md) |

### Cómo leer este portafolio

Los casos describen capacidades presentes en el código y separan las comprobaciones realizadas de las validaciones pendientes. La selección demuestra trabajo técnico; no implica una certificación de producción ni una prueba completa de cada aplicación en dispositivos.

El código fuente de estos tres proyectos se mantiene **privado**. Las fichas se pueden leer sin acceso al código; sus enlaces técnicos requieren permiso. El acceso para una evaluación puede coordinarse con el propietario desde su [perfil de GitHub](https://github.com/AndersonGamboaGamboa).
