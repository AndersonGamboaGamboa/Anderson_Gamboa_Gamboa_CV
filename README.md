# Anderson Gamboa Gamboa
## Portafolio de evidencias · Desarrollo de software

Selección de proyectos de gestión agropecuaria, administrativa y educativa con aplicaciones móviles, sistemas web y servicios de backend.

**Tecnologías presentes:** C#, ASP.NET Core, .NET MAUI, TypeScript, React Native, Expo, MySQL, PostgreSQL, HTML, CSS y Bootstrap.

### Cómo leer este portafolio

Los casos describen capacidades presentes en el código y separan las comprobaciones realizadas de las validaciones pendientes. La selección demuestra trabajo técnico; no implica una certificación de producción ni una prueba completa de cada aplicación en dispositivos.

El código fuente de Ganado Manager, Porcino Manager, Cosecha Manager y GAMA se mantiene **privado**. El proyecto colaborativo de la escuela incluye una [copia pública del código](codigo/fausto-gestion-academica/) y la atribución al equipo original. Las fichas se pueden leer sin acceso al código; sus enlaces técnicos requieren permiso. El acceso para una evaluación puede coordinarse con el propietario desde su [perfil de GitHub](https://github.com/AndersonGamboaGamboa).
