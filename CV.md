## Proyectos seleccionados

- **Ganado Manager · C#, ASP.NET Core, .NET MAUI y MySQL.** Gestión de animales, inventarios y movimientos económicos, con separación por finca y verificaciones automatizadas de regresión e integración.
- **Porcino Manager · TypeScript, React Native, Expo y Node.js.** Gestión de engorde, alimentación y ventas con reglas de existencias y costos; 47 pruebas móviles aprobadas en la revisión.
- **Cosecha Manager · TypeScript, React Native y PostgreSQL.** Registro de recolección de café y pagos por trabajador, con reglas de saldos, calendario y ajustes; 13 pruebas de dominio aprobadas en la revisión.

- **GAMA · C# y ASP.NET Core MVC.** Sistema de gestión de participantes, actividades, salud y roles, organizado en capas de presentación, lógica de negocio y acceso a datos. Código revisado; compilación y recorrido funcional pendientes de verificar.

- **Escuela Fausto Herrera Cordero · HTML, CSS, JavaScript y Bootstrap.** Participación en un prototipo académico colaborativo, con aportes documentados en módulos de prematrícula, permisos, tickets, activos, mantenimiento e insumos, además de ajustes de navegación. Se presenta como trabajo de frontend, sin backend operativo.

## Adaptación a una vacante

Para puestos .NET/backend, presentar primero Ganado Manager. Para puestos TypeScript o móviles, presentar primero Porcino Manager y luego Cosecha Manager.

Estas frases describen los proyectos. Antes de incluirlas como experiencia personal, precisar la contribución propia y, cuando corresponda, el trabajo del equipo. No atribuyen autoría exclusiva, experiencia laboral, cantidad de usuarios ni resultados comerciales no comprobados.
